# Mod icons

Icons extracted from `ModAPI.meta.icon(...)` when present in the mod source.

- `icons.json` maps mod filename (e.g. `AsyncSink.js`) to a `data:image/png;base64,...` URL (resized to max 64×64).
- Mods not listed here have no embedded icon; the website shows `?`.

Source: files under [`mods/`](../mods/).
